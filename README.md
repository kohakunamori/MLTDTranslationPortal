# MLTD 汉化查阅站

这是《偶像大师 百万现场 剧场时光》（MLTD）个人汉化项目的内容查阅站。

[打开查阅站](https://mltd-portal.nyaneko.cn)

可以按分类浏览、搜索汉化文本，查阅歌词、术语及图片。内容随汉化进度持续更新。
歌词支持同曲合并展示、按默认歌唱偶像筛选，并可在阅读时切换歌曲版本。

相关项目：[汉化资源](https://github.com/kohakunamori/MLTDTranslationAssets) · [汉化版下载](https://github.com/kohakunamori/MLTDTranslationClient/releases)
